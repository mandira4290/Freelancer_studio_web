Freelancer Studio Web

Portfolio and client-enquiry website for a freelance Java Full Stack Developer. The frontend is an animated, responsive single page, and the backend is a Spring Boot REST API that saves every enquiry to a cloud MySQL database.

🔗 Live demo: https://freelancer-studio-web.onrender.com

Hosted on a free plan, so if the site has been idle the first load can take up to a minute.

Features
Contact / enquiry form – sends JSON to a REST API (POST /api/inquiries) and stores it in MySQL.
Responsive design – works on mobile, tablet and desktop (CSS Grid and Flexbox).
Light and dark theme – follows the visitor's device setting.
Animations – text reveal, scroll-triggered effects (IntersectionObserver), 3D card tilt, animated counters, scroll progress bar, custom cursor and a scrolling marquee.
Accessibility – animations are switched off for visitors who prefer reduced motion.
Project showcase with a demo video.
